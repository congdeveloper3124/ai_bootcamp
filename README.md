# AI Bootcamp

Welcome to the **AI Bootcamp** repository! This repo contains materials, exercises, and projects for the AI Bootcamp program.

## 📚 About

This bootcamp is designed to help participants learn the fundamentals of AI and machine learning through hands-on sessions, covering topics such as:

- Introduction to AI/ML concepts
- Data preprocessing and analysis
- Model building and training
- Real-world project implementation

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/congdeveloper3124/ai_bootcamp.git
   ```
2. Navigate into the project directory:
   ```bash
   cd ai_bootcamp
   ```
3. Follow the instructions in each session folder to get started.

## 🌿 Branches

- `main` — stable, reviewed content
- `feature/session_1` — Session 1 materials and exercises
